---- Step 2: GRB 090510 -- naive single-photon-pair bound vs. published ----

Vasileiou et al. 2013 (Phys. Rev. D 87, 122001), using dedicated multi-photon
statistical techniques on the full LAT sample, report E_QG,1 > 7.6 * E_Planck.
This crude estimator instead uses only the single ~31 GeV photon's arrival
time (0.829s post-trigger) vs. a ~keV reference -- it should land in the same
order of magnitude but BELOW 7.6, since it throws away most of the statistical
power the paper's methods use.

(Since naive E_QG(ell) = hbar*c/ell scales as 1/ell, the exclusion threshold is
ell* = ell_Planck / 7.6 = 2.127e-36 m. Under this naive ansatz, GRB 090510 alone
already excludes EVERY discreteness length coarser than roughly the Planck length
itself -- there is essentially no room left between "continuum" and "excluded".
Any discrete-spacetime model that wants a lattice spacing at or above the Planck
length AND survives this bound needs an explicit suppression mechanism for LIV,
not just "discreteness exists" -- exactly what serious QG programs with an
emergent, not fundamental, discreteness build in.)

================================================================
 What this crate does NOT (yet) claim: a discreteness length FROM
 spectral_dqg's own hypergraph. The hypergraph has no committed
 physical edge length, so mapping graph combinatorics -> a length

 crate doesn't currently have. This module is the machinery that
 calibration would plug into, not a claim that it's been done.
